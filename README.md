## Featured projects

### [Cambodia Job Market Analysis](https://github.com/menghong-heng/job-market-analysis)

Built an automated ETL pipeline for **12,000+ job postings across 13 Cambodian job portals**. Modeled the data in a PostgreSQL star schema and built Power BI dashboards for salary benchmarks, in-demand skills, and regional hiring patterns.

**Stack** · Python, BeautifulSoup, Pandas, SQLAlchemy, PostgreSQL, Power BI, Docker

### [E-Commerce Sales Pipeline](https://github.com/menghong-heng/E_Commerce_Analysis)

Built a Python pipeline to clean and load Amazon sales records into MySQL. Designed a relational schema with access controls and order fulfillment tracking.

**Stack** · Python, Pandas, SQLAlchemy, MySQL, Jupyter

### [Trustpilot Sentiment Classifier](https://github.com/menghong-heng/beautiful_soup_scrape)

Scraped consumer reviews and trained a multiclass sentiment classifier using TF-IDF and logistic regression. The model reached **77.7% test accuracy** and **0.78 weighted F1**. Deployed a Streamlit app for live predictions.

**Stack** · Python, BeautifulSoup, scikit-learn, Streamlit, Joblib
